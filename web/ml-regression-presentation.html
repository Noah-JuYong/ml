1. 회귀(Regression)란?

자연 현상(또는 사회 현상)에서 여러 변수들 사이의 관계를 찾아 모델링하는 방법

일상적인 예시

📚 공부 시간 → 수능 성적

공부를 더 하면 성적이 얼마나 오를까?

✊ 노조 파업 → 성과급

파업이 성과급에 어떤 영향을 미칠까?

🚲 따릉이 수요 예측

날씨, 요일, 시간대별로 따릉이 이용량은?

핵심: "어떤 것이 어떤 것에 영향을 주는가?" → 그 관계를 수식으로 표현하는 것

2. 변수의 종류

🔵 독립변수 (피처, Feature)

  • 영향을 주는 변수
  • 예: 공부 시간, 기온, 방 개수
  • 우리가 이미 알고 있는 데이터
  • 기호: x

🔴 종속변수 (레이블, Label)

  • 영향을 받는 변수
  • 예: 시험 점수, 라면 판매량, 집값
  • 우리가 예측하고 싶은 데이터
  • 기호: y

3. 단순 vs 다중 회귀

📐 단순 선형 회귀

  • 독립변수 1개 (x)
  • 종속변수 1개 (y)
y = w₀ + w₁x

→ 1차 함수 (직선) 형태

학습 목표: w₀, w₁ 값을 찾아라

📊 다중 선형 회귀

  • 독립변수 n개 (x₁, x₂, … xₙ)
  • 종속변수 1개 (y)
y = w₀ + w₁x₁ + w₂x₂ + … + wₙxₙ

→ 다차원 함수 (평면/초평면)

학습 목표: w₀, w₁, … wₙ을 모두 찾아라

💡 용어 정리: 머신러닝에서는 w를 "회귀 계수", 딥러닝에서는 "가중치(Weight)"라고 부릅니다.

4. "학습"이란 무엇인가?

학습 = 오차(에러)를 최소로 만드는 회귀 계수(w)를 찾는 과정

학습의 반복 과정

① 초기값 설정
→
② 예측
→
③ 오차 계산
→
④ w 조정
→
⑤ 반복 → 오차 최소화

핵심: 예측값과 실제값의 차이(오차)가 0에 가까울수록 성능이 좋은 모델

5. RSS (비용 함수, Cost Function)

RSS = Residual Sum of Squares (잔차 제곱합)

오차의 제곱을 모두 더한 값. 이 값을 최소로 만드는 것이 학습 목표

RSS = Σ (실제값 - 예측값)²

왜 제곱할까?

🔍 이유 1

오차가 양수일 수도, 음수일 수도 있어요. 제곱하면 모두 양수가 되어 합산 가능.

🔍 이유 2

오차가 크면 제곱해서 더 크게 만들어서, 큰 오차에 더 민감하게 반응.

단순 vs 다중 회귀의 RSS

단순 선형 회귀 (1개 피처)

RSS = Σ(yᵢ - (w₀ + w₁xᵢ))²

다중 선형 회귀 (n개 피처)

RSS = Σ(yᵢ - (w₀ + w₁xᵢ₁ + … + wₙxᵢₙ))²

6. 코드 — 데이터 준비 & 분석

import numpy as np import pandas as pd import matplotlib.pyplot as plt import seaborn as sns from sklearn.datasets import fetch_california_housing # 캘리포니아 주택 가격 데이터 가져오기 house = fetch_california_housing() # 데이터 설명 출력 print(house.DESCR) # 정답 데이터 (각 집의 실제 가격) house.target

설명: fetch_california_housing()는 sklearn에 미리 들어있는 데이터셋. 20,640개 주택 데이터.

# 피처 8개 + 정답 1개로 DataFrame 구성 house_df = pd.DataFrame(house.data, columns=house.feature_names) house_df['target'] = house.target house_df.shape # 결과: (20640, 9) → 20,640개 데이터 × 9개 컬럼

설명: pd.DataFrame는 엑셀처럼 테이블로 정리. 8개 피처 + 1개 타겟 = 총 9개 컬럼.

7. 코드 — EDA (상관관계 분석)

# 2행 4열 = 8개의 작은 그래프 공간 fig, ax = plt.subplots(nrows=2, ncols=4, figsize=(16,8)) # 각 피처별로 산점도 + 회귀선 그리기 for idx, feat_nm in enumerate(house.feature_names): sns.regplot(x=feat_nm, y='target', data=house_df, ax=ax[int(idx/4)][idx%4]) plt.show()

그래프 해석

📈 우상향 ↑

양의 상관관계 — 피처 ↑ → 집값 ↑

예: MedInc (소득) → 소득 높을수록 비쌈

📉 우하향 ↓

음의 상관관계 — 피처 ↑ → 집값 ↓

예: Longitude (경도) → 동쪽일수록 비쌈

📊 무작위 ⚡

상관관계 약함 — 예측에 도움 안 됨

상관계수: 강한(>0.7) / 약한(<0.3) / 보통(0.3~0.7)

VIF: 피처들 중복 확인. VIF > 10이면 제거.

8. 코드 — 모델 학습 & 예측

# 라이브러리 from sklearn.linear_model import LinearRegression from sklearn.model_selection import train_test_split from sklearn.metrics import mean_squared_error # 1) X(피처), y(타겟) 분리 X = house_df.drop('target', axis=1) y = house_df['target'] # 2) 학습용 75% + 검증용 25% 분할 X_train, X_test, y_train, y_test = train_test_split(X, y, random_state=0) # 3) 모델 생성 & 학습 lr = LinearRegression() lr.fit(X_train, y_train) # 4) 검증 데이터로 예측 y_pred = lr.predict(X_test)

train_test_split: 학습용(75%) + 검증용(25%) 나눔. 검증 데이터는 모델이 안 본 "시험 문제".

random_state=0: 매번 같은 기준으로 나누기 위한 시드 값.

9. 코드 — 모델 평가

# MSE (평균 제곱 오차) mse = mean_squared_error(y_test, y_pred) # RMSE (제곱근 평균 제곱 오차) rmse = np.sqrt(mse) # 회귀 계수 확인 print(lr.intercept_) # w₀ (y절편, 편향) print(lr.coef_) # w₁~w₈ (각 피처의 회귀 계수) # R² 점수 (0~1): 집값 변동의 몇 % 설명 accuracy = lr.score(X_test, y_test) # 결과: 약 0.59 → 59% 설명 가능

평가 지표 비교

MSE (평균 제곱 오차)

오차 제곱의 평균

단위가 제곱이라 해석 어려움

RMSE (제곱근 평균 제곱 오차)

MSE의 제곱근

원래 단위(백만 달러)로 복원

예: RMSE=0.73 → 평균 73만 달러 오차

💡 참고: RMSE = 0.73 → 평균 73만 달러 오차. 더 낮을수록 좋음.

10. 완성된 모델의 수식

집값 = -36.61 + 0.44 × MedInc (평균 소득) + -0.01 × HouseAge (주택 연령) + 0.04 × AveRooms (평균 방 개수) + 0.02 × AveBedrms (평균 침실 개수) + -0.02 × Population (인구) + -0.01 × AveOccup (거주율) + -4.31 × Longitude (경도) + -0.12 × Latitude (위도)

해석: MedInc(소득) 계수 0.44로 가장 큼 → 소득↑ → 집값↑ 경향. Longitude -4.31로 가장 큰 음수 → 동쪽일수록 집값↓.

모델 성능: RMSE ≈ 0.73 (73만 달러 오차) | R² ≈ 0.59 (59% 설명)

11. 교차 검증 (Cross-Validation)

왜 필요한가? 한 번의 분할만 쓰면 운에 따라 결과가 달라질 수 있음. 여러 번 반복하여 안정적인 점수 얻기.

from sklearn.model_selection import cross_val_score lr = LinearRegression() # 5-fold 교차 검증 mse = cross_val_score(lr, X_train, y_train, cv=5, scoring="neg_mean_squared_error") rmse = np.sqrt(-1 * mse) np.mean(rmse) # 결과: 0.73 → 0.72로 약간 개선
